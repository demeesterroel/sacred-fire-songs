# 🔥Sacred Fire Songs
🎵 A collaborative web application for ceremonial musicians. Features real-time transposition, ABC notation for melody playback, setlist management, and offline caching for use in remote environments.

* *The Mission*: To bridge oral tradition and accessibility, allowing community members to learn and practice songs with accurate lyrics, chords, and melodies.
* *Key Tech*: Built with Next.js, Tailwind CSS, and Supabase, utilizing abcjs for sheet music rendering and TanStack Query for robust offline caching.
* *Target Users*: Designed specifically for Guitareros (musicians needing transposition) and ceremony participants (needing large, readable lyrics).
